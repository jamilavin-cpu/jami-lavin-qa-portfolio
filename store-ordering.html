QA CASE STUDY

Store Supply Ordering Platform

Provided QA support for an online ordering platform by validating end-to-end order fulfillment workflows across customer-facing applications and integrated ERP systems.

Overview

Supported quality assurance for a web-based ordering platform used by stores to purchase supplies. Testing focused on order creation, integration with Microsoft Dynamics NAV, fulfillment processing, and accurate status communication between systems.

Business Workflow

Store places order through website
↓
Order data is pushed to Microsoft Dynamics NAV
↓
Order is located and processed in NAV
↓
Shipment status is updated
↓
Updated status is returned to website

My Role

  • Performed end-to-end functional testing of ordering workflows
  • Validated order creation through the website
  • Executed integration scripts to validate order information transfer between systems.
  • Verified order processing and shipment updates in Microsoft Dynamics NAV
  • Validated returned status information displayed on the website
  • Identified defects and documented findings for resolution

Testing Approach

Website Testing

Validated order entry, user workflows, and expected customer-facing behavior.

ERP Validation

Verified order processing steps within Microsoft Dynamics NAV.

Integration Workflow Testing

Validated information flow between systems and confirmed status updates.

Challenges & Solutions

Challenge: The ordering workflow required accurate data movement between the website and Microsoft Dynamics NAV to ensure orders were processed correctly.

Solution: Performed end-to-end workflow validation by testing order submission, integration processing, fulfillment updates, and status synchronization between systems.

Tools Used

Testing Tools

Azure DevOps, manual test execution, defect tracking, and test documentation.

Systems Validated

Web-based ordering platform and Microsoft Dynamics NAV ERP system.

Testing Methods

End-to-end testing, integration testing, workflow validation, and data verification.

Quality Impact

Increased confidence in the ordering process by validating critical workflows across multiple applications, ensuring accurate order processing, fulfillment updates, and communication between integrated systems.
